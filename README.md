# Keito

A whimsical block theme for crafters' blogs, starting with crochet. Keito (毛糸) is Japanese for "yarn."

- **Design:** the spec, preview, and style guides live in `~/Projects/themes/keito/design/` (spec: `design-system.md`). Build from the spec, not from the preview's CSS.
- **Review link:** https://keito.view.fast/ (private to derek-team)
- **Project notes:** `~/Workshop/products/keito.md`

Core blocks only: no custom post types, custom blocks, or shortcodes. Every value comes from a theme.json preset.
